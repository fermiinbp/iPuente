## Usuarios objetivo
 
- **Empresas y profesionales** que necesitan una sala por horas para charlas, formaciones, reuniones, presentaciones o eventos.
- **Empresas que ya trabajan en el edificio** y necesitan una sala extra puntualmente.
- **Personal de gestión del edificio**, que administra salas, reservas y pagos.
## Historias de usuario
 
| ID | Historia |
| --- | --- |
| HU-01 | Como **visitante**, quiero explorar el edificio en 3D y elegir una planta, para hacerme una idea del espacio sin ir en persona. |
| HU-02 | Como **visitante**, quiero ver en el plano de cada planta qué salas están libres en una fecha, para saber rápido qué opciones tengo. |
| HU-03 | Como **visitante**, quiero ver el precio, la capacidad, los m² y el equipamiento de una sala, para saber si encaja con mi evento antes de registrarme. |
| HU-04 | Como **visitante**, quiero registrarme con mi email o mi cuenta de Google, para poder reservar sin rellenar formularios largos. |
| HU-05 | Como **usuario**, quiero reservar una sala por fecha y franja horaria y pagarla online, para cerrar el alquiler en un solo paso. |
| HU-06 | Como **usuario**, quiero ver y cancelar mis reservas, para gestionar cambios de planes sin llamar a recepción. |
| HU-07 | Como **administrador**, quiero crear y editar plantas y salas con sus precios y fotos, para mantener la información siempre al día. |
| HU-08 | Como **administrador**, quiero ver todas las reservas y pagos, y poder cancelar, bloquear salas o reembolsar, para controlar la ocupación y resolver incidencias. |
| HU-09 | Como **administrador**, quiero cambiar el rol de un usuario, para dar acceso al panel al resto del personal. |
